## §1 問題

1. **保單散落**：一個家庭常有多家公司、多位被保人的保單，紙本與各公司 App 分散，需要時找不到保單號碼、客服電話與保障內容。
2. **到期與繳費漏接**：定期險、車險、旅平險到期，或繳費日錯過，可能造成停效或保障中斷。
3. **出險時不知道怎麼理賠**：不清楚要準備哪些文件、向誰申請、有無時效；文件備齊與否沒有清單可追。

本產品只做**整理、提醒與流程清單**。不比較保險商品優劣、不推薦或銷售保險、不媒合業務員、不代為申請理賠、不判斷是否應理賠。

## §3 獲利模式

| 模式 | 適用性 | 說明 |
|---|---|---|
| 免費增值（建議） | 中低 | 本機版免費；付費候選為家人保單夾、密碼加密備份、PDF 保單總表。價格**待驗證**（舊版 NT$99／月、免費 5 張上限為內部假設，程式未實作上限）。 |
| SaaS 訂閱（備選） | 待驗證 | 給持照業務員／經紀人管理客戶既有保單。使用者本身持照，工具方不招攬；但會集中處理第三人的特種個資，需要後端、加密、存取控制與委託處理約定，M2 驗證後另案。 |
| 模板販售 | 低 | 理賠文件清單、家庭保單整理表的模板。營收小但風險低，可作為驗證需求的工具。 |
| 專案建置、顧問／內訓 | 不建議 | 與保險業務邊界不清，容易被認為提供保險建議。 |
| 導購佣金、名單轉介、保險公司廣告 | **不做** | 未經許可從事保險經紀、代理或招攬，並向保險業收取報酬，可能違反保險法（§8）。 |

## §8 資料、個資與法規

> 本節為產品規劃用的風險盤點，不是法律意見。條號與要件以現行法規為準，正式對外前須由律師確認（列為待決事項）。

### 8.1 資料分級

| 等級 | 欄位 | M1 處理 |
|---|---|---|
| S（特種個資候選） | 理賠事由、診斷、手術、癌症、失能、身故等出險資訊；診斷書等文件 | 只存本機；M1 只記「文件是否備齊」與自由文字備註，不上傳檔案；UI 預設不顯示理賠備註全文 |
| P（一般個資） | 被保人、要保人、家人姓名、保單號碼 | 只存本機；列表可遮罩保單號碼；匯出檔加個資警示 |
| B（契約資料） | 公司、險種、保額、保費、期間、除外責任 | 只存本機 |
| R（參考資料） | 保險公司地址、電話、官網、條款網址、SOP 文字 | 每筆須有來源與查證日期；未查證不顯示或明確標示 |

### 8.2 法規邊界

| 主題 | 規範（待法律確認） | 產品對策 |
|---|---|---|
| 保險招攬、經紀、代理 | 保險法對保險業務員（第 8-1 條）、保險經紀人（第 9 條）有定義；經營經紀、代理業務須經主管機關許可並取得執業證照（第 163 條），未經許可從事者有罰則（第 167-1 條）；另有保險業務員管理規則 | 不推薦、不比較商品優劣、不提供投保建議、不導購、不媒合業務員、不收保險業或業務員的轉介報酬、不放保險商品廣告 |
| 「條款比較」 | 比較自己已持有保單的欄位屬資訊整理；但標示「最佳」或比較市售商品可能被視為建議或招攬 | FR-009 中立呈現；不建立市售商品資料庫 |
| 公司評比 | 以未查證的申訴率標紅公司，可能有商譽、公平交易法不實比較等爭議 | FR-012 移除 |
| 個資法：特種個資 | 個資法第 6 條將醫療、健康檢查等列為特種個資，原則不得蒐集處理，例外包括當事人書面同意等（要件待確認） | M1／M2 資料只存使用者裝置，營運方不蒐集；上雲端（FR-025）或 B2B（FR-026）前須律師意見、書面同意設計、加密與委託處理約定 |
| 個資法：告知 | 營運方若蒐集任何個資（含帳號、聯絡方式）須依第 8 條告知 | M1 不蒐集；M2 訪談招募另備告知同意書 |
| 家人資料 | 替家人建檔涉及第三人資料 | UI 提示「請取得家人同意」；資料不離開裝置 |
| 理賠時效 | 保險法第 65 條：由保險契約所生之權利，自得為請求之日起經過 2 年不行使而消滅（例外與起算點待確認） | FR-008 提醒只作提示，文字標「實際以契約與法律為準」 |
| 代辦理賠 | 代填、代送理賠申請是否涉及需執照的業務**待確認** | FR-024 延後；M1 只做清單 |

### 8.3 資料來源

| 資料 | 現況 | 合法取得與呈現方式（待確認） |
|---|---|---|
| 保險商品條款 | 未收錄；`termsUrl` 多為猜測路徑 | 只連結到各公司官網的商品資訊揭露頁或公會的商品查詢頁，不轉載條款全文（條款著作權歸屬待確認）；M1 移除未查證的 `termsUrl` |
| 申訴率 | `companies.ts` 示意值 | 移除。若未來要呈現，只引用主管機關或評議機構公開統計，附期間與原始連結 |
| 客服電話、地址 | 未查證、有重複 | 逐筆查證官網並記錄 `sourceUrl`、`verifiedAt`；未查證者 M1 不顯示 |
| 理賠 SOP | 無出處，時程（T+3、T+7）為自訂 | 改寫為「常見需備文件」，標註「依各保險公司理賠申請書要求為準」，並列參考來源 |
| 地圖圖磚 | OpenStreetMap 公用圖磚 | 遵守 OSM 圖磚使用政策與標示；正式上線若流量變大需改用自有或付費圖磚（待確認） |
